Offline Licensing with Optional Internet Time Verification

Objective: Prevent license expiration bypass through system clock changes while keeping the application usable offline most of the time.

Strategy:

Store the last successful run date.
Compare current system date with last run date.
If the date moves backward (or jumps suspiciously far forward), verify against an internet time source.
Otherwise run completely offline.
if (currentDate < lastRunDate)
{
    currentDate = GetInternetTime();
}

This reduces internet usage to only suspicious cases while catching the most common clock-tampering attempts.

var license = LoadLicense();

{
    MessageBox.Show("License expired");

}

One extra improvement

Store the latest trusted date:
trustedDate = Max(lastRunDate, currentDate);

and never allow it to decrease.

Conceptually:
trustedDate = max(lastRunDate,systemDate,internetDateIfChecked);

Phase 3: Protect the License File
--------------------------------------------------
Without protection, a user can edit:

in  .json file: 
{
  "ExpiryDate": "2035-01-01"
}

and get a free extension.

This is where RSA signatures come in.

Create RSA Keys

Generate:
Private Key  <-- only you have this
Public Key   <-- embedded in app

####License Generator (your tool.. keep it with us)

Your tool creates:
.json file

{
  "Customer": "Client A",
  "ExpiryDate": "2027-01-01"
}

Then signs it:

License Data + Digital Signature

Result:
.json
{
  "Customer": "Client A",
  "ExpiryDate": "2027-01-01",
  "Signature": "abc123..."
}

####Client Application

When loading (c#):

VerifySignature(
    licenseData,
    signature,
    publicKey);

If verification fails:

MessageBox.Show("Invalid license");
Application.Exit();

Now users can't modify expiry dates.

For a first real implementation, I'd stop at:
✅ Expiry date
✅ Last-run-date protection
✅ RSA-signed license file
Those three features provide most of the value and are a solid foundation before adding machine binding or online activation.

Step 1 — Generate RSA Keys (DO THIS ONCE)

Run this once in a console app C#:

using System.Security.Cryptography;
using System.IO;

var rsa = RSA.Create(2048);

File.WriteAllText("privateKey.xml", rsa.ToXmlString(true));   // keep secret
File.WriteAllText("publicKey.xml", rsa.ToXmlString(false));   // embed in app
Result:
privateKey.xml → ONLY YOU
publicKey.xml → goes inside client app
